# Odiliya Premier Luxury Homepage

## Run
```bash
npm install
npm run dev
```

## Design
- Georgia, Times New Roman, serif across the entire interface
- Black / white / warm off-white luxury theme
- clamp(), vw and vh responsive sizing
- Sri Lanka luxury apartment business sections
